# Changelog

## Azeroth Guidebook v3.16.0

- Added specialization-specific **Activity Profiles** for Raid, Mythic+, and Delves.
- Profiles remember the player's selected sources across guide domains, U.GG content context, talent category/build selections, Wowhead gear set, and Rotation context/preset.
- Profiles are isolated per specialization.
- Added Modified detection and profile update behavior.
- Preserved source-aware My Character auditing and Character Action Plan navigation while switching profiles.
- Added official Azeroth Guidebook branding to the minimap launcher and AddOn Compartment.

## Azeroth Guidebook v3.15.0

- Added **What's New Since Last Refresh?**
- Added five-run Recent Refresh History.
- Added domain-level comparison for Talents, Gear/BiS, Consumables, Enchants & Gems, Stats, and Rotation when before/after snapshots are available.
- Separates recommendation changes from source-date-only updates.
- Added direct navigation from changed domains to the updated guide.
- All-sources refresh compacts unchanged detail.

## Azeroth Guidebook v3.14.0

- Added the **Character Action Plan**.
- Consolidates actionable talent, gear, enchant, and consumable issues from the player's currently selected guide sources and contexts.
- Added optional Completed rows and direct navigation into the affected guide.
- Preserved U.GG observational wording and conservative handling of alternatives.

## Azeroth Guidebook v3.13.0

- Added end-user one-click refresh controls for Current Source, Current Spec, and All Sources.
- Added optional native Windows companion integration.
- Added companion status, notifications, and fail-closed local source overrides.

For detailed historical development notes, see `addon/AzerothGuidebook/CHANGELOG.md`.
